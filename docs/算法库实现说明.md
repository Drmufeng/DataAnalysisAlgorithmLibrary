# 算法库实现说明

## 1. 文档状态

- 状态：第一版算法实现说明。
- 更新时间：2026-08-18。
- 适用范围：算法 SDK、8 个算法包、CLI、本地执行器和统一测试。

## 2. 项目边界

本项目与平台项目独立维护。算法代码只接收平台准备好的表格、字段槽位、参数和运行上下文，返回统一结构化结果。算法不得：

- 自行读取用户上传文件。
- 访问平台数据库或对象存储。
- 调用 FastAPI、启动常驻服务或访问网络。
- 写死开发电脑的绝对路径。
- 直接生成 ECharts 配置或最终 HTML 报告。

## 3. 当前调用流程

```text
读取 manifest.json
→ 校验算法包、依赖和入口
→ 读取 AlgorithmRequest
→ 校验字段槽位、字段标签和参数
→ 动态加载 package_id + version 对应入口
→ 使用 DataFrame 副本运行算法
→ 校验 AlgorithmResult
→ 输出严格 JSON 和可选 Parquet
```

命令行执行器每次只运行一个算法步骤。平台后续可以通过子进程调用它，并负责超时、取消、资源配额和任务状态；这些平台职责不写入算法函数。

## 4. 运行输入

运行请求包含：

- `operation_key`：`algorithm_id.method_id`。
- `slots`：字段角色和所选字段。
- `parameters`：经过 Schema 约束的普通参数。
- `context`：运行编号、步骤编号、协议版本、语言、随机种子和字段元数据快照。

字段元数据同时记录实际类型和当前定类/定量标签。执行器还会根据 pandas 数据再次判断实际类型，避免只相信客户端标签。

## 5. 运行输出

算法返回 `AlgorithmResult`：

- `data`：数据处理后的 DataFrame；纯分析算法为空。
- `metrics`：关键指标。
- `tables`：统计表和预览表。
- `charts`：与前端框架无关的图表数据描述。
- `warnings`：不阻止运行但需要展示的说明。
- `metadata`：输入输出行列数、方法和字段摘要。

写入 JSON 前统一把 NumPy 标量、时间和缺失值转换为标准 JSON 值，并使用 `allow_nan=false` 做最终检查。DataFrame 单独使用 Parquet 保存，避免把大表塞进 JSON。

## 6. 错误边界

预期错误使用 `ProtocolError`，目前包括参数、字段、数据、依赖、执行、取消和内部错误类型。CLI 返回：

```json
{
  "status": "error",
  "error": {
    "code": "COLUMN_ERROR",
    "message": "字段槽位 columns 至少需要 1 个字段",
    "details": {"slot": "columns"}
  }
}
```

用户结果不包含 Python 堆栈和服务器路径。未知异常由执行进程记录后转换为通用执行错误，平台以后负责保存关联日志。

## 7. 算法包清单

`manifest.json` 使用 Pydantic 做固定结构校验，并额外检查：

- 协议版本和三段式包版本。
- 包、算法和方法编号格式及重复编号。
- 字段槽位数量、类型、定类/定量和约束引用。
- 参数 JSON Schema 是否有效。
- 协议 `1.1` 的中英文展示元数据是否完整，参数和枚举能否由平台通用渲染。
- 依赖是否存在且版本满足。
- 入口模块是否位于算法包内部、函数是否存在且具有四个协议参数。

当前校验针对受信任算法包，不能等同于恶意 Python 代码沙箱。

## 8. 当前算法

第一版共包含 8 个算法包、31 项算法功能和 53 个可执行方法：

- 描述性分析：数据概览、频数、列联、描述统计、分类汇总和正态性检验。
- 数据处理：数据编码、异常值处理和无效样本处理。
- 时序与信号：滑窗转换和三种降采样。
- 统计关联：自动求解、三种相关、一致性、典型相关、泊松和游程检验。
- 统计模型：OLS、岭回归、分层回归、GM(1,1) 和 PCA。
- 聚类与分类：K-Means、DBSCAN、逻辑回归、三种朴素贝叶斯和 LightGBM。

“变量类型与标签设置”由平台保存为字段元数据，不登记为算法；实际编码、分箱或改写数据才由数据处理算法执行。

## 9. 当前验证状态

- 全部 manifest、参数 Schema、依赖和入口通过 CLI 校验。
- 全部 53 个 `operation_key` 至少有一个真实运行用例。
- 数据处理输出新 DataFrame，纯分析方法不返回数据版本。
- 随机算法使用固定种子可以复现。
- 关键统计量与 SciPy、statsmodels、scikit-learn 或手工结果对照。
- Ruff、严格 MyPy、Pytest、Wheel 和源码包构建通过。

下一步是平台侧算法包导入登记、启停、任务调度和结果落库；这些职责不加入算法函数。
