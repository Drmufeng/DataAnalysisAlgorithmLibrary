# 报告排版协议

算法运行结果可以通过 `ReportPresentationSpec` 声明报告排版，但仍保持与具体网页框架无关。

## 基本规则

- 区块只引用同一次结果中的指标、表格或图表编号。
- `table` 和 `chart` 区块必须有引用编号。
- 区块编号和排序号不能重复。
- 排版声明不复制数据，不保存 HTML，不保存 ECharts `option`。
- 旧算法不提供排版声明时，平台使用统一默认布局。

支持的区块类型为 `metrics`、`table`、`chart`、`text`、`warnings` 和 `metadata`；宽度为 `full`、`half`、`third` 和 `two_thirds`。

这种方式保证算法升级可以在算法库内调整图表和结果顺序，同时让网页、PDF 和 Word 报告复用同一份结构化结果。
