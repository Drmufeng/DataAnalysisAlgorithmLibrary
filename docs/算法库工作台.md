# 算法库工作台

## 1. 定位

算法库工作台是独立算法库项目内的本地桌面开发工具，不属于平台管理端或用户端。它负责改善算法维护体验，但不改变清单协议、运行协议和完整发行包流程。

工作台直接读写源码仓库中的真实文件：

```text
library_manifest.json
└─ 内部模块 manifest.json
   └─ 算法组
      └─ 可执行方法 entry
         └─ Python 源码和入口函数
```

使用 IDE 修改文件和使用工作台修改文件具有相同结果，不存在额外数据库或私有工程格式。

## 2. 当前界面

第一版界面使用三栏工作区：

- 左侧是完整发行包、模块、算法和方法树，并提供即时搜索。
- 中间是可关闭、可排序的真实文件标签页，提供行号和基础语法高亮。
- 右侧显示当前节点对应的协议元数据。
- 底部显示校验、测试和构建命令的实时输出。

选择具体方法时，工作台解析 `module:function` 入口，打开实际 `.py` 文件并跳转到函数定义行。选择模块或完整发行包时打开对应清单文件。

## 3. 新增算法和方法

工具栏中的“新增算法”可以向现有模块增加一个算法组及其首个方法；先在左侧选择模块、算法或方法，工作台会自动带入对应上下文。“新增方法”则向当前选中的算法组增加一个方法。

向导会收集算法/方法编号、中英文名称与说明、输入变量模式、变量类型和输出类型，并一次性生成或更新：

- 模块 `manifest.json` 和根 `library_manifest.json`。
- 可直接继续实现的 Python 入口文件。
- 对应方法的独立 Pytest 骨架。
- `tests/studio_operation_cases.json` 中的最小整库运行用例。
- 模块和完整算法库的补丁版本。

写入完成后会立即执行整库协议校验。任何文件冲突、清单错误或校验失败都会回滚本次创建，不留下只登记了一半的算法。

## 4. 技术与许可

- Qt 绑定：PySide6，按 LGPL 方式动态使用。
- 界面主题：`PyQtDarkTheme-fork`，MIT。
- 代码编辑：Qt 原生 `QPlainTextEdit` 和 `QSyntaxHighlighter`。
- 运行命令：复用 `algorithm_cli`、Pytest 和 `build`。

工作台不使用 GPL 版 QFluentWidgets 或 QScintilla。桌面依赖放在 `studio` 可选依赖组中，不进入 Worker 和算法执行环境。

## 5. 当前边界

当前版本已经覆盖浏览、源码修改、新建算法/方法和现有质量命令的统一入口。后续可以继续增加：

- 新建完整模块向导。
- 字段槽位和参数 Schema 的表单化编辑。
- 示例数据试运行和结构化结果预览。
- 文件差异、版本升级和构建产物历史。
- 基于 Python AST 的函数、类和导入结构导航。

新增能力仍然写入既有清单和 Python 文件，不引入第二套算法定义。
